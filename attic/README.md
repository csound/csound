# Old tools

This folder keeps old tools and build scripts.

`longline.c` checks line lengths, tabs, and spacing. Run it from the repository
root so it can read `all_string_files` and the source paths listed there.

`dependencies/` holds the old Mac OS X dependency build scripts and PortMIDI
patches. Their README describes builds for OS X 10.8 on i386 and x86_64.
See [BUILD.md](../BUILD.md) for current build instructions.
